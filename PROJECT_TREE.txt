Quick Command Reference
=======================

Setup:
  npm install
  Copy-Item .env.example .env
  notepad .env

Basic Usage:
  node src/index.js list-skills
  node src/index.js find -s SKILL_ID
  node src/index.js find -s SKILL_ID -o report.csv

Removal:
  node src/index.js remove -s SKILL_ID --dry-run
  node src/index.js backup -s SKILL_ID
  node src/index.js remove -s SKILL_ID -e all

Help:
  node src/index.js --help


Features Implemented
====================

Phase 1 (Read-Only):
  ✓ List all skills
  ✓ Find dependencies (users, canned responses)
  ✓ Export to JSON/CSV
  ✓ Pretty console tables
  ✓ Placeholder for engagements/widgets

Phase 2 (Write Operations):
  ✓ Remove skill from users
  ✓ Remove skill from canned responses
  ✓ Delete skill after cleanup
  ✓ Dry-run mode
  ✓ Automatic backups
  ✓ Batch processing
  ✓ Error handling

Infrastructure:
  ✓ OAuth 2.0 authentication
  ✓ Domain API integration
  ✓ Token caching and refresh
  ✓ Retry logic with backoff
  ✓ Rate limit handling
  ✓ Comprehensive logging
  ✓ Windows compatibility


External APIs Integrated
=========================

1. Domain API
   - Get base URIs for services
   - Endpoint: api.liveperson.net

2. Skills API
   - List, get, delete skills
   - Service: accountConfigReadOnly/ReadWrite

3. Users API
   - List, get, update users
   - Filter by skillIds

4. Predefined Content API
   - List, get, update canned responses
   - Filter by skillIds


Internal APIs (Manual Capture Required)

2. Widgets API
